# 盤あわせ

将棋の対局を**アームで真上から撮った動画**から、棋譜を起こすためのアプリ。

**いまは第0段。**「その撮り方でいけるか」を目で見て決めるところまで。
まだ駒は読んでいないし、棋譜も出ない。

姉妹アプリに [棋譜ノート](https://github.com/kakugawari/kifu) がある。
あちらは対局の**あと**に手で書くもの。こちらは**撮った動画から起こす**もの。

## 使いかた

```
npm start          # http://localhost:8080/
```

1. **動画か写真をえらぶ** — MP4 / MOV、または写真1枚。写真でも撮り方は確かめられる
2. **はじめの駒を並べたところを出す**（動画のとき）— つまみを動かしてコマを選ぶ
3. **盤の四隅を合わせる** — 4つの点を指で動かす。つまむと虫めがねが出る
4. **先手はどちら側？** — 手前（下）か、奥（上）
5. **まっすぐに直した盤**が出て、撮り方の点検結果が並ぶ

合わせるのは**マス目の外側の線**の四隅です。木の縁ではありません。

### マス目を重ねる

四隅から計算した 9×9 のマス目を、**元の写真の上に重ねて出します**。
この線が盤の線に乗っていれば、四隅は合っています。ここが一番の確かめどころ。

直した盤のほうには四隅のマスの名前（`９一` `１一` `９九` `１九`）が出ます。
**向きを取り違えていれば、ここで分かります。**

## 点検の見かた

| 項目 | ◎ | △ | × | 直しかた |
|---|---|---|---|---|
| 真上からの度合い | 5%まで | 15%まで | それ以上 | カメラを盤の真ん中の真上へ。盤から離すほど落ち着く |
| 1マスの大きさ | 60画素以上 | 36画素以上 | それ未満 | 盤が画面の横幅いっぱいになるまで寄せる |
| 盤のまわり方 | 3°まで | 8°まで | それ以上 | 盤の辺と画面の辺をそろえる（記録はできる） |

「真上からの度合い」は、**奥のマスと手前のマスの大きさが何%違うか**です。
真上から撮れていれば 0%。斜めになるほど大きくなります。

## 撮りかた

- **アームで盤の真上から。** iPhone は**縦**
- **標準レンズ（1x）で、盤から 1.5〜2 倍の高さ。** 超広角（0.5x）は使わない。
  近づけて広角で撮ると盤の辺が外へふくらみ、**この歪みは射影変換では直せません**
- **盤だけを横幅いっぱいに。駒台は切れてかまいません。**
  持ち駒は盤の履歴から計算できるので、写す必要がありません
- **1080p で十分。** 盤が横幅の9割なら 1マス約 107 画素。4K にしても重くなるだけ
- アームや iPhone の**影が盤に落ちていないか**、撮る前に見てください

## 開発

```
npm test           # 算数のテスト (node --test)
npm run test:ui    # ブラウザで動かすテスト (要 npm i -D playwright)
```

`core.js` は DOM を触らないので node で試せます。射影変換のテストは
**必ず台形で**行っています。真四角だけで試すと、ずれていても差が出ないためです。

`npm run test:ui` は本物のブラウザに**作った盤の写真を流しこんで**、
指で四隅を動かすところまで再現します。
とくに「先手が手前／奥」の取り違えは、印を置いたマスが動くかどうかで見張っています。

- 四隅の自動検出（いまは手で合わせる。自動は後から足します）
- オフライン対応（ホーム画面に追加）

## これから

| 段 | 中身 |
|---|---|
| 0 | **盤あわせ**（いまここ） |
| 1 | 9×9 の駒の有無・向き・成りを盤に重ねて出す |
| 2 | コマ間の差分を合法手と照らして、1手に決める |
| 3 | 迷ったら3択で聞く。手で直せるようにする |
| 4 | **消費時間つきの KIF** を書き出す |

消費時間は、動画のコマの時刻から出せます。
**手で書く棋譜では原理的に取れない情報**なので、検討の材料としてはここが一番おいしいはずです。
